# SWI revision 02 — research to experiments

The user rejected the first release's content depth and visual design on 2026-09-06. This revision supersedes the four-record home and earlier visual contract. The user explicitly selected framework-independent agent packages. This is an implementation direction chosen for the requested redesign, not a claim of a new user design approval.

## Product contract

The primary surface is a usable research workbench. Eight biological dossiers connect observations, mechanisms, transfer boundaries, original agent recipes, primary literature and controlled experiments. A curated research library spans foundational work and contemporary multi-agent studies. Every study has provenance, publication/revision information, review date, reading depth, finding, engineering interpretation and limitation.

The agenda accepts manually entered URLs and notes, UTF-8 Markdown/text files, and versioned SWI JSON backups. It stores entries in the current browser; no shared server, cloud sync, automatic scraping or automatic publication is represented as available. Entries can be edited, classified, linked to a mechanism, exported, restored and archived with undo. Public research and personal notes remain separate.

Recipes export Markdown instructions and JSON experiment specifications. Exports carry the actual task, roles, topology, aggregate budget, stop conditions, metrics, source links and comparison plan. They do not execute models. Interactive topology diagrams describe the recipe rather than inventing benchmark scores.

## Intentional corrections to image text

Scientific accuracy overrides generated sample copy. Honeybee consensus is not proof of truth: use “Kanıtı karşılaştır, itirazı kaybetme.” Format labels say “arXiv sürümü” when peer-review status is not established. Reading dates refer to the editorial snapshot, not a live feed. UI labels use complete Turkish/English parity. Dossier row diagrams represent communication mechanisms, not anatomically authoritative animal drawings.

Verification will cover native desktop/mobile viewports, typography, palette, image framing, navigation, source disclosures, filters, recipe output, agenda import/export/persistence/recovery, accessibility and zero overflow. The fidelity ledger records the resulting comparisons.
